# Montreal FunGuide - a RESTful Web Service

### <i>Welcome to the Montreal Funguide!</i>

    The Montreal FunGuide is a RESTful web service that provides a plentitude of information regarding various fungi species you can find right here in your backyard. This service also includes fun things to do like recipes you can cook or trips you can take to find fungi all over the city. There is a map included in this service with locations thanks to the abundance of data received from our Composite APIs.
